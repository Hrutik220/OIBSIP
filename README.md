# Nmap Network Scanning

## Objective
Find open ports and services using Nmap.

## Tools 

- Kali linux
- Nmap 7.99
- Windows 10
- VirtualBox 

## Target 

IP: 192.168.50.20

## Open Ports 

- 135: MSRPC
- 139: NetBIOS
- 445: SMB
-3389: Remote Desktop

## security Risks 

Open ports may expose services to attackers.
Use strong passwords, restrict access, and update Windows.
